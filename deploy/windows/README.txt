Requant — тестовая сеть: майнер для Windows
===========================================

Это тестовая сеть: монеты не имеют ценности, сеть может быть перезапущена.
Награды идут на адрес из config.bat (ADDRESS / PAYEE).

Требования
- Windows 10 или 11, 64 бит.
- Видеокарта NVIDIA: Turing и новее (GTX 16xx, RTX 20xx/30xx/40xx/50xx, CMP).
- Свежий драйвер NVIDIA (рекомендуется последний; минимум 528 для CUDA 12).
- ~1,5 ГБ видеопамяти, ~1,5 ГБ оперативной памяти для ноды, интернет.

Запуск
1. Распакуйте архив в папку без русских букв в пути, например C:\Requant.
2. selftest.bat — проверка видеокарты (должно быть "sha256 ok, expansion ok").
3. start-all.bat — запускает ноду (окно "Requant node") и через 20 секунд майнер.
   Можно запускать по отдельности: start-node.bat, затем start-miner.bat.
4. balance.bat — баланс и последние операции адреса наград.

Что в окнах
- Нода: синхронизирует цепь с сидами (193.187.93.29, 193.32.188.248, 185.174.40.96).
  При первом запуске ~10 секунд готовит веса эпохи (512 МБ).
- Майнер: "M tickets/s" — скорость; "block N accepted" — найден блок.
  Примерно: CMP 50HX 3,4 M/s, RTX 3090 6,3 M/s.
- Награда за блок созревает через 100 блоков (~1,5 часа): до этого она "immature".

Настройки (config.bat)
- PAYEE / ADDRESS — куда идут награды. Свой кошелёк:
    requant-wallet.exe keygen my.key --network test
  затем впишите "key hash" в PAYEE и "address" в ADDRESS. Файл my.key храните в секрете.
- DEVICE — номер видеокарты (0, 1, ...). Для нескольких карт скопируйте start-miner.bat
  и задайте в копии свой DEVICE.
- BATCH — строк за проход; на картах с 4 ГБ и меньше поставьте 2048.

Если что-то не так
- Антивирус может ругаться на майнер (cppminer.exe) — это типично для майнеров; добавьте папку в исключения.
- "getwork failed" в майнере — нода не запущена или ещё стартует.
- Подробнее: https://github.com/danifest751/requant (TESTNET.md).
